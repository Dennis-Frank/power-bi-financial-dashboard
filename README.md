# power-bi-financial-dashboard

## Overview

This project explores financial performance data using Microsoft
Power BI. The interactive dashboard provides an overview of sales,
profit, and profit margin across countries, product segments, and time.

## Objectives

- Analyze overall sales and profit.
- Compare financial performance across countries.
- Evaluate sales and profit across product segments.
- Explore sales trends over time.
- Enable interactive analysis using filters.

## Tools & Technologies

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data visualization and exploratory data analysis

## Key Features

- KPI cards for total sales, total profit, and profit margin
- Sales comparison by country
- Sales and profit comparison by segment
- Sales trend over time
- Interactive filters for country and segment

## Data

The project uses Microsoft's Financial Sample dataset.
